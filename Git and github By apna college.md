1. Git aur GitHub ka Ta'aruf (0:00 - 5:00)
Git: Yeh ek 'Version Control System' hai jo code ki history track karta hai aur team collaboration mein madad deta hai.
GitHub: Yeh ek online platform hai jahan aap apna code store aur manage kar sakte hain.

2. Setup aur Installation (16:45 - 20:30)
VS Code: Coding ke liye istemal hone wala software.
Git Configuration: git config --global user.name "Name" ke zariye apna naam aur email set karna zaroori hai.

3. Zaruri Git Commands (25:23 - 40:00)

git clone: Kisi dusre ki repository ko apne computer par lana.
git init: Ek folder ko Git repository mein badalna.
git status: File ka current status check karna (Modified, Staged, ya Untracked).
git add: File ko 'Staging Area' mein daalne ke liye.
git commit: Changes ko save karne aur unka snapshot lene ke liye.
git push: Apne local code ko GitHub par upload karna.

4. Branching aur Collaboration (44:41 - 55:20)
Branch: Main code se alag copy bana kar us par kaam karna.
git branch: Branch check karna.
git checkout: Ek branch se dusri branch par jana.
Merge: Do branches ke code ko aapas mein jodna.

5. Merge Conflicts aur Reset (1:02:43 - 1:11:00)
Merge Conflict: Jab do branches mein same line par alag badlav hon, toh Git confuse ho jata hai. Ise manually theek karna parta hai.
git reset: Ghalat commit ko undo karne ke liye. --hard ka use karne se code aur commit dono revert ho jate hain.

6. Forking (1:12:03 - 1:12:50)
Fork: Kisi aur ke project ki copy apne account mein banana taake aap us par contribute kar sakein.
